Support

Commandes, destinations et aide pour Orbital Puck sur Apple Vision Pro.

Nous contacter

Décris ta question. Pour un problème, indique la version de visionOS, la version de l’app, la destination et le mode de commande.

Le formulaire envoie ton nom, ton e-mail et ton message à Web3Forms pour nous les transmettre. Évite les données sensibles. Consulte notre politique de confidentialité.

Premiers pas

Entrer et commencer

Choisis Entrer dans le café, puis Commencer la partie sur la console de score. Le premier à sept points gagne.

Guider la raquette

Autorise le suivi des mains, puis déplace ta main droite à plat. Bloque doucement ou frappe rapidement pour accélérer le palet. Utilise Centrer ou Recentrer la main pour ajuster le repère.

Utiliser le pincement

Dans Réglages du poste, choisis Pincement. Regarde la raquette turquoise, pince et déplace-la. Ce mode est disponible si le suivi des mains est refusé et dans le simulateur.

Changer de destination

Ouvre le sas derrière toi ou choisis Ouvrir le sas · Destinations. Sélectionne l’une des neuf cartes, puis démarre une nouvelle partie. Ouvrir le sas suspend le match ; fermer permet de le reprendre.

Questions fréquentes

La main sort du champ ?

Garde ta main droite visible devant toi un instant pour reprendre le suivi. Au bord de la table, ramène la main dans la zone de jeu. Si le suivi reste indisponible, utilise le pincement.

Comment ajuster le confort et le son ?

Les réglages proposent la hauteur de table, la pause, le recentrage et un interrupteur pour l’ambiance et les bruitages. Prends une pause si tu ressens une gêne.

Comment changer de langue ?

Choisis le français ou l’anglais dans la préférence de langue de l’app, puis relance Orbital Puck. La langue suit les réglages système de visionOS.

Faut-il un compte ?

Aucun compte de jeu n’est nécessaire. Le jeu est solo ; le formulaire de support est indépendant de l’app.
